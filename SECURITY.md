# Security Policy

Please do not open public issues for suspected vulnerabilities in SecDoctor itself. Use GitHub's private vulnerability reporting once the repository is published.

SecDoctor is a defensive local auditing tool. Fix & Verify modifies project lockfiles only after an explicit preview and confirmation. Keep source control or an independent backup for important projects.

Reports should include the SecDoctor version, operating system, affected command/workflow, minimal reproduction, and expected vs actual behavior. Do not include real secrets, tokens, private source code, or customer data.
